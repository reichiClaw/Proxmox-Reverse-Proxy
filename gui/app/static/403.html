403 — IP allowlist

Traefik blocked this request because your client IP is not in admin-allowlist. By default Gate is public (password auth); this page only appears if that optional middleware was enabled.

Common causes:

  • Opening https://gate.<domain> via the public WAN / hairpin NAT (Traefik sees your public IP)
  • Cloudflare proxy (orange cloud) — Traefik sees Cloudflare’s IPs
  • Accessing from the internet or a mobile network

Quick fixes

  1. From a LAN machine, put 10.x.x.x gate.your.domain in /etc/hosts (gate CT IP) and retry — source IP stays private.
  2. Or grey-cloud the gate record in Cloudflare (DNS only).
  3. Or add your client IP under sourceRange in config/dynamic/middlewares.yml and wait for Traefik to reload.

See Traefik access logs for the blocked IP: journalctl -u traefik -n 50 | grep 403
